# Mobile AI Assistant & UI Optimization

The Synalux portal provides a global AI Assistant and mobile-friendly text entry for supported workflows.

## Global AI Chat Assistant
The AI Chat is available from a floating action button across the platform.
1. **Plan-aware assistance** — the available response quality and model choices follow the workspace plan and administrator policy.
2. **Conversation continuity** — minimizing the assistant does not discard the current conversation while the user reviews another screen.
3. **Mobile-safe layout** — inputs remain above the operating-system home indicator on supported phones and tablets.

## Native Predictive Text
Supported text fields use the device's native spelling and predictive-text controls. This keeps ordinary keyboard suggestions on the user's device instead of sending keystrokes to a separate suggestion service.
