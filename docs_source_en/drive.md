# Drive

Drive keeps workspace files in one searchable customer screen. Open [synalux.ai/drive](https://synalux.ai/drive) after signing in.

## Upload and find workspace files

1. Open **Drive** and choose **Upload**.
2. Select one or more files. Each file can be up to 50 MB.
3. Keep the page open while the progress list shows each file as queued, uploading, completed, or failed.
4. Use the Drive search control to filter the file list by title.

A failed file does not remove other files that completed in the same batch. Review the message beside the failed file, correct the issue, and upload it again.

## Open, save, and delete

- **View** opens the selected workspace file.
- **Save** downloads a copy after the product checks your access.
- **Delete** appears only when your role for that file permits deletion. Confirm the filename carefully; the current customer screen does not promise a recycle-bin recovery period.

## Connected storage

The Drive screen can connect Google Drive and shows connected Google Drive files in the external-files section. You can search, preview supported formats, open a file in Google Drive, and load more results.

The screen also offers a OneDrive connection control. The current external-file browser documented here is Google Drive; do not assume that connecting OneDrive makes OneDrive files appear in the same browser until your organization has verified that workflow.

## Access and privacy

Files are shown according to your signed-in account and active workspace. Before uploading sensitive information, confirm that you are in the correct workspace and that the file belongs in Drive. Share files only through an organization-approved workflow; this page does not document public links or per-recipient sharing permissions.
