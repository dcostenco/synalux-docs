# 📝 Practice Drive & Collaboration

Synalux provides a collaboration workspace and Practice Drive for the files available to your signed-in account. The exact file types, editing tools, and external connections depend on your workspace configuration and permissions.

Use this page to open the collaboration tools enabled for your organization. Access to a tool does not grant access to every file; file visibility follows workspace permissions.

## Practice Drive

Practice Drive lists the documents, spreadsheets, presentations, and other supported files available to you. Select a file to open it in the corresponding workspace. If external drive connections are enabled, their availability is shown separately.

## Safe use

- Verify that you are working in the intended workspace before opening or sharing a file.
- Confirm recipients and permissions before adding patient or business information.
- Use the editing, sharing, and version features that are actually shown for the selected file type.
- Follow your organization’s retention and export policies for downloaded or externally connected files.
