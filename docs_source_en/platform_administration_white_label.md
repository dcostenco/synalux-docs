# ⚙️ Platform Administration & Branding

Synalux administration brings location visibility, branding, roles, audit activity, and finance access into role-controlled workspaces. The controls shown to each administrator depend on the organization’s plan and permissions.

## Multi-location dashboard

Authorized administrators can review the locations and summary information available to their organization. Confirm each location’s access and configuration before staff begin using it.

Users with finance access can review the accounting workspace, including the available summary metrics, ledger activity, compliance reminders, and connection status. Currency and access are configured per workspace.
