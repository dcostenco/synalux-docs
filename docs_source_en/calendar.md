# Calendar

Open [Synalux Calendar](https://synalux.ai/calendar) to view connected Google Calendar and Microsoft 365 calendars in one workspace.

## Connect a calendar

1. Open **Calendar**.
2. If no calendar is connected, select **Connect Google** or **Connect Microsoft**.
3. Review the provider's consent screen and approve only the account you intend to use.
4. Return to Synalux and select the connected calendar from the sidebar.

Connection availability depends on the organization and the provider account. A successful connection must appear in Synalux before its events can be managed.

## Browse and manage events

Use list, day, week, or month view. Search by event title, location, or description. Select an event to review it, then choose **Edit** or **Delete** when the connected calendar permits the action. Select **New Event** to create an event in the currently selected calendar.

Failed provider updates remain visible as errors; verify the event in Synalux after creating, editing, or deleting it.

## Video-call links

The event form can ask the connected calendar provider to add its native video call: Google Meet for Google or Microsoft Teams for Microsoft. Zoom appears only when it is enabled for the account and available under the current plan. Selecting an event keeps the calendar view in Synalux; selecting a video-call link opens the approved conferencing destination.

## Calendar versus clinical scheduling

Use **Schedule** for patient appointments, provider/location filters, authorization warnings, recurring clinical visits, waitlist handling, and patient-portal requests. Synalux Calendar manages connected provider events; it does not automatically create patient appointments from authorized units or attach tasks and patient records to every calendar event.
