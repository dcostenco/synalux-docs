# Referrals & Care Coordination

Use the **Referrals** tab in a patient chart to review referral records associated with that patient.

## Referral tracking

The current patient view shows:

- Sent date
- Receiving provider or organization
- Referral reason
- Urgency
- Current status

An alert calls attention to an urgent referral that is still pending. The pending count in the tab header provides a quick workload cue.

## Communication

Synalux Team Chat and Direct Messages are separate communication tools for authorized users. They are not embedded in the current patient **Referrals** tab, so opening a referral does not open a dedicated conversation thread.

## Current referral boundary

The patient Referral tab is currently a status view. It does not expose controls for creating or editing a referral, sharing attachments, recording read receipts, or managing referral authorizations. Use **Authorizations** for authorization numbers, approved units, effective dates, utilization, and renewal tracking.
