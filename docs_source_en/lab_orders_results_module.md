# Lab Orders & Results

The **Labs** tab in a patient chart brings available lab orders and their results into one review screen.

## What the chart shows

Each order can show its order number, laboratory or vendor name, ordered date, and status. Results nested under the order can show:

- Test name and code
- Result value and unit
- Reference range
- Abnormal flag with visual emphasis

This makes the patient chart useful for reviewing results already delivered to Synalux.

## Current workflow boundary

The current patient-chart tab does not expose controls for creating an order, choosing routine/urgent/stat priority, attaching diagnosis codes, marking a result reviewed, or routing an order to Quest Diagnostics or Labcorp. Lab exchange and result import depend on the practice's configured integration. Synalux does not automatically create iPLEDGE, presurgical, or medication-monitoring lab panels from this screen.
