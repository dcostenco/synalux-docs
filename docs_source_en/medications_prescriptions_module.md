# Medications & Prescriptions

The **Medications** tab in a patient chart provides a quick view of medication records available to Synalux.

## What the chart shows

The table displays:

- Medication name
- Dose
- Frequency
- Prescriber reference
- Status

The active-medication count also appears in the patient summary and links back to this tab.

## Current prescribing boundary

The current patient-chart tab is a review screen. It does not provide a drug catalog, prescription-entry form, refill workflow, drug-interaction checking, pharmacy routing, controlled-substance workflow, or iPLEDGE tracking. Continue to use the practice's authorized prescribing system for clinical prescribing decisions and record exchange.
